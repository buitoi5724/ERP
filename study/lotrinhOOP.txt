6. Constructor with Validation 
Là contructor cho và nhằm để kiểm tra dữ liệu đầu vào khi thêm vào biến  rồi mới cho thêm dữu liệu vào để đảm bảo dữ liệu hợp lệ
Không phải truyền gì cũng được mà phải kiểm tra trước rồi mới thêm vào nếu sai sẽ bị từ chối 
ví dụ :
package Java_Contructor;

public class Constructor_with_Validation {
 
	String name ;
	int age ;
	
	Constructor_with_Validation( String name , int age  ){
		if(name == null || name.isEmpty()) {
			this.name = " Unknown";
		}else {
			this.name = name ;
		}
		if(age < 0 ) {
			this.age = 0 ;
			
		}else {
			this.age = age ;	
		}
	}
		void display () {
			System.out.println(name + " - " + age);	
	}
		public static void    main (String[]args) {
			Constructor_with_Validation c1 = new Constructor_with_Validation("BuiToi" , 22);
			Constructor_with_Validation c2 = new Constructor_with_Validation("  " , 4 ) ;
			c1.display();
			c2.display();
		
	}	
}
Kết luận : 
Là cho phép contructor kiểm tra dữ liệu trước khi thêm dữ liệu vào biến để kiểm tra rồi mới thêm nếu không hợp lệ sẽ không được thêm

10. Constructor for Singleton Pattern
là là một class có duy nhất mọt objectvà cung cấp các đỉm truy cập toàn cục cho intance đó và chỉ có một objectđó ai cũng có thể dùng chung 
ví dụ : 
package Java_Contructor;

public class Constructor_for_Singleton_Pattern {

	private static  Constructor_for_Singleton_Pattern instance  ;
	String name ;
	
	private Constructor_for_Singleton_Pattern() {
		name = "BuiToi";
		
	}
	/**
	 * @return the instence
	 */
	public static Constructor_for_Singleton_Pattern getInstence() {
		if (instance   == null) {
			instance   = new Constructor_for_Singleton_Pattern();
		}
		return instance  ;
	}

	/**
	 * @return the name
	 */
	public String getName() {
		return name;
	}
	/**
	 * @param name the name to set
	 */
	public void setName(String name) {
		this.name = name;
	}
	
	public static void main (String[]args) {
		Constructor_for_Singleton_Pattern c1 = Constructor_for_Singleton_Pattern.getInstence();
		Constructor_for_Singleton_Pattern c2 = Constructor_for_Singleton_Pattern.getInstence();
		
		
		c1.setName(" BuiToi1");
		System.out.println(c2.getName());

		System.out.println(c1 == c2 );
		
	}
	
}
Kết luận : là một design đảm bảo cho một class có duy nhất một intance object và cung cấp cho một ddiemr truy cập toàn bộ đến intance đó

package Java_Static_Members;

9.Inner Class with Constructor
Là class nằm bên trong 1 class và có contructor để khởi tạo đối tượng thì phải tạo object thì phải thông object của lớp ngoài 
ví dụ : 
package java_Nested_Classes;

public class Inner_Class_with_Constructor {

	class Students {
		String name ;
		int age ;


		Students(String name , int age ){
			this.name = name ;
			this.age = age;
		}


		class Address {
			String city ;
			String state ;
			String sreet ;
			String zipcode;


			Address( String city , String state , String sreet , String zipcode){
				this.city = city ;
				this.sreet = sreet;
				this.state = state ;
				this.zipcode = zipcode;

			}
			void display() {
				System.out.println("Tên học sinh: " + name);
				System.out.println("Tuổi: " + age);
				System.out.println("Thành phố: " + city);
				System.out.println("Bang: " + state);
				System.out.println("Đường: " + sreet);
				System.out.println("Zipcode: " + zipcode);
			}
		}
	}
	public static void main(String[] args) {
		Inner_Class_with_Constructor ch = new Inner_Class_with_Constructor();
		Inner_Class_with_Constructor.Students st = ch.new Students ( " Tới Bùi  " , 22) ;
		Inner_Class_with_Constructor.Students.Address add = st.new Address (" hà Nôi " ," Hoàng mai " , "Vĩnh Hưng" , "10000" );

		add.display();
	}
}
Kết Luận : 
Có class năm bên trong của class và có constructor khi khỏi tạo đối tượng của nó nhưng khi tạo  object thì sẽ thông qua object của lớp bên ngoài
